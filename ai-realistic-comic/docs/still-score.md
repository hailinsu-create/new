# 双人静帧打分

人工目视用。自动评委仍是 `judge_still` 的八项（`qa.py` 里的 `STILL_KEYS`）。八项均分不够用：蛇头尾尖、鱼尾、点错的耳朵会被其它高分拉过 7.5。所以先过硬门，再算均分。

合格：没有硬门失败，且八项均分 ≥ `comic_still_min_score`（7.5）。`anatomy` 低于 6 也算硬门，和现有管线一致。

## 硬门

任一失败即不合格，均分只作记录。

| 门 | 不合格 |
| --- | --- |
| H1 尾型 | 鱼尾、鱼鳍、尾鳍、鲸尾 |
| H2 尾尖 | 第二颗蛇头、断开的珍珠球、细柄接球。尾尖应是同一条尾巴的粗圆钝端 |
| H3 形态 | 蛇身腰以下仍有人腿或脚；人身长出尾巴。样张亭中盘蛇允许腰上白衣，但不许裙子下面另藏一双腿 |
| H4 耳 | 珀耳塞福涅尖耳；哈迪斯圆耳 |
| H5 人数 | 不是正好两人、多出一张脸、拼贴或分屏 |
| H6 成年 | 看起来像未成年人 |
| H7 手 | 看得见的手多指、多一只手、断肢。被挡住的手指不算 |

## 八项（各 0–10，等权）

身份、区分、互动、美感、解剖、服装、动机、摄影感。定义与 `judge_still` 相同。摄影感：实拍为高分，插画、3D、游戏 CG 接近 0。

动机对照五张已批准样张：雨桥、亭中盘蛇、王座喂籽，以及同组的湖上船沿。不要求像素级复刻。
