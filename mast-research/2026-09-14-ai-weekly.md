## 本期六条核心边际（机制语言）

1. **推理需求在放量，模型层在用价格换份额。** 全球周 Token 调用约 **115 万亿**，相对约 8 个月前增超 **17 倍**；综合 Token 有效价格约 **0.68**，相对 3 月高点 **1.15** 累计约 **-41%**（OpenRouter 2026-09-07；Citi 2026-09-08；国内卖方 2026-09-11）。量的一阶仍在，价的一阶在让利。
2. **算力租金仍在高位，但卡种内部已经劈叉。** 海外 H100 一年期合约自 2025-10 约 **$1.70/h** 升至 2026-09 约 **$3.06/h**（累计约 **+80%**）；当周即期却是新卡 B200 **+6.3%**、旧旗舰 H100 **-9.4%**（Ornn 2026-09-13）。缺口叙事还在，结构已经换成「新卡紧、旧卡晃」。
3. **存储不再是一块板：HBM/DRAM 挤出 vs NAND 消费疲软。** DDR4 16Gb 现货反超 DDR5 约 **+67%** 这种倒挂极少见；NAND 现货连续 **3 周**下跌（TrendForce 2026-09-07）。同一条存储链，训练/推理内存和消费闪存走的是反方向。
4. **财报把「量价背离」钉死在中游硬件。** 海外 GPU 龙头数据中心收入 **+117%**、晶圆代工 8 月营收 **+53%**、某云厂商云业务 **+121%** 均超预期；同期 GPU 服务器**出货量 -10.8%**、均价 **+43.6%**（NVIDIA 8/26；台积电 9/11；甲骨文 9/10；IDC 9/10）。景气在价和结构，不在箱数二阶。
5. **政策/地缘是情绪脉冲，不是已经定性的产能开关。** 9/12 OpenAI 与 Anthropic 联合呼吁「放缓前沿 AI」；9/10 Anthropic 发布 154 页报告，指控 7 家中国实验室约 **1.9 亿次**非法蒸馏交互。国内卖方把短线情绪读成偏空硬件、中长线读成头部集中与网络安全（Anthropic 9/10；国内卖方 9/14）。**指控未经司法定性，中方否认。**
6. **卖方仍看多 capex，但分歧从「要不要买算力」换成「谁付得起、付到哪一年」。** 投行上修海外 GPU 龙头目标价区间至约 **$300–400**（卖方观点，不是操作指令）；MS 警示 2027 云 capex 增速放缓；微软是当期**唯一明确下调 capex 指引**并取消/推迟约 **2GW** 租约的巨头；BIS 警告 AI capex 泡沫（GS 9/10；MS 9/10；BIS 9/10）。瓶颈叙事从「需求够不够」转回 **ABF / HBM / 电力 / 信用** 这些实体约束。

## 下游 Token 量价：以价换量 / 流量与付费错位 / 对算力结构含义

### 量：仍在扩张，但周环比陡降

OpenRouter 口径（8/31–9/6，经财联社/每经 2026-09-07）：

- 全球周调用 **115 万亿 Token**，当周 **+1.77%**。上一期曾 **+21.11%**，环比斜率明显掉档。
- 中国模型周调用 **56.72 万亿（+2.83%）**；美国模型 **16.54 万亿（-3.1%）**。
- 份额约 **中国 56% / 美系 14.4%**，中国连续 **19 周**高于美国。
- 前五模型合计约 **50.1%**，其中 **4 款为中国模型**。

机制读法：这不是「需求消失」，是**高基数后的斜率回落**。份额上，流量重心在中国模型；这与下面的变现结构是两张图。

### 价：综合有效价被打穿，区域与前沿层却在分化

Citi 2026-09-08：

- 全市场平均推理单价约 **0.97 $/百万 Token（-4.9%）**。
- 美国+欧盟均价 **1.80（+26.8%）**；中国均价 **0.91（持平）**。
- 前沿模型均价 **1.44（+18.0%）**。
- 综合 Token 有效价格 **0.68**，相对 3 月高点 **1.15** 累计 **-41%**。

叠加产品层动作：某国产开源阵营 Flash 档 9/10 **再降价 60%**；OpenAI 新一代 Astra 定价提到上代 **2.5 倍**。同一周里同时出现「中低端继续打折」和「前沿涨价」——这是**分层定价**，不是铁板一块的价格崩。

### 流量与付费错位

爱分析 2026-09-09 给出一串国内模型 ARR 量级（此处不点名、不当作买卖清单）。机制上只需记住两句：

- 中国模型拿走约 **56% 流量**，但流量冠军不必是变现冠军。
- Anthropic 以约 **12% 流量**拿走平台约 **46% 收入**（雪球转述，口径弱于 OpenRouter 原数，当结构线索而非审计数）。

观察框架：看 Token 曲线时，至少拆三列——**调用量、有效单价、可归集 ARR**。任何一列单独创新高，都不能推出「模型厂利润同步变好」。

### 对算力结构的含义

KV Cache 被压到约 **1/4**，直接改的是芯片购物清单：推理芯片与高带宽互联的权重上升，训练卡占比相对下降。再叠加「以价换量」，中游不该再被理解成铁板「训练 GPU 景气」——更贴近的句子是：

> **推理工作负载加速摊到更多 Token 上；单 Token 更便宜；单次推理对缓存/带宽/互连更敏感。**

条件化观察：若下一阶段出现「Token 量也走平 + 有效价继续跌」，模型层会先伤；若「量继续高增、价分层（前沿稳住、长尾继续打）」，压力更多留在中小模型与二线云，不一定立刻打穿高端卡租金。

## 中游 GPU 租金：新旧卡分化、挂牌 vs 成交

Ornn 2026-09-13 即期（美元/小时）：

- H100 SXM **2.78**，周 **-9.4%**，月仍 **+12.5%**
- H200 **4.38**，周 **-2.0%**
- B200 **7.06**，周 **+6.3%**，月 **+11.65%**
- A100 **1.03**，周 **-2.8%**
- 消费级高端 RTX 5090 **0.73**，周 **+17.7%**（更像短供给脉冲，不与数据中心卡同一叙事）

期限结构：H100 **一年期合约** 2025-10 → 2026-09，**$1.70 → $3.06，约 +80%**。即期可以一周摔 9%，长约仍记录「缺口被锁进合同」。

国内云：**当周挂牌价持平**，但 H200 整机买断约 **545 万/台**连涨三档，月租 **>14 万/台（+25%–30%）**。挂牌是橱窗，买断和长租才是成交。

供需斜率（报告转述）：Q1 AI 算力需求 **+417%** vs 供给 **+128%**；GPU 服务器出货 **-10.8%**、均价 **+43.6%**。箱数在减、单箱在贵——典型的**量跌价升**。旧卡长周期贬值、待部署库存，是卖方自己列出的负面项，与「当期硬件价仍强」并不矛盾。

观察框架（非操作）：

- 只看 H100 即期一周，会误判「算力崩了」。
- 只看一年期 +80%，会忽略新卡溢价、旧卡周波动已经开始。
- 同时看：**新卡即期、旧卡即期、一年期、买断价、出货量二阶**。五者同向才是强确认；本期是**价与结构确认、箱数二阶警告**。

证伪萌芽：若 B200 类新卡即期也连续走弱，且一年期掉头，才更接近「缺口叙事松动」；单周 H100 回吐不够。

## 上游存储：DRAM / HBM vs NAND 劈叉

TrendForce 2026-09-07：

- DDR5 16Gb 约 **$50.69（+0.15%）**，几乎走平。
- DDR4 16Gb 约 **$84.64**，反超 DDR5 约 **+67%**——把「新规格永远更贵」这条直觉直接打穿。倒挂更像 **HBM 挤占成熟 DRAM 产能 + 利基/旧规格供给收缩**，不是消费 PC 突然爱 DDR4。
- 512Gb TLC NAND wafer 约 **$20.146（-2.71%）**，连续 3 周跌。
- HBM 约占 DRAM 晶圆投入 **22–23%**，挤出普通 DRAM。
- 韩系原厂库存不足 **10 天**（产业转述）。
- NAND：**现货跌、合约仍 +20%** 的反向劈叉——现货先反映消费疲软，合约还停在旧景气。
- 利基 NOR / SLC / 利基 DRAM 涨幅巨大，与 HBM 主线是「产能挤出」的同一类机制。
- HBM **现货约 4–5 倍长协**——利润弹性的核心不在「有没有 HBM」，在**现货溢价能否维持、长协何时补涨或回归**。

机制一句话：AI 把存储切成两条河。一条河（HBM / 被挤出的 DRAM / 利基）在缺；另一条河（消费 NAND）在吐。用 NAND 弱去空整个存储，或用 DRAM 强去多整个存储，都是把劈叉当成板。

证伪：DDR4/DDR5 倒挂快速收敛且韩系库存回补到正常周数，挤出叙事降温；NAND 现货止跌并与合约同向，消费端假设要重写。

## 财报与 capex：收入兑现 vs FCF 转负 / 微软节奏调整

### 收入侧：兑现，而且偏「价与云」

- 海外 GPU 龙头数据中心 **+117%**（8/26）
- 台积电 8 月营收 **+53.3%**（9/11）
- 甲骨文云 **+121%**，capex 约 **$285 亿**（9/10）
- 微软把 2032 年数据中心容量叙事从约 **12GW 提到 38GW**——长期仍扩

这些是公开财报/月营收口径，用来确认：**上游制造和云账单仍在兑现金字塔上半截。**

### 现金与指引：不是同一张表

- 多数巨头 capex 指引上修。
- **微软是当期唯一明确下调 capex（日历口径）并取消/推迟约 2GW 租约的一家**；长期容量目标仍在扩张。这是**节奏调整，不是退出军备**。
- 甲骨文 FCF 约 **-54 亿**；Alphabet Q2 FCF 约 **-59 亿**。收入高增、自由现金流转负：扩建把现金提前锁进机柜、电力和芯片。

卖方层（不当事实）：Capex 高度看多；瓶颈叙事转向实体供给（ABF、HBM4E）；MS 警示 **2027 云 capex 增速放缓**；GS 警示标普盈利增长近半依赖少数买家；BIS 警告泡沫。负面清单里还有：旧卡长周期贬值、出货量二阶下滑、NAND 疲软、消费电子减配、待部署库存。

### 必须单独列出的 capex 分化（≠「放缓前沿」）

| 观察对象 | 本期事实（报告内） | 机制含义 |
| --- | --- | --- |
| 能力迭代政策倡议 | OpenAI / Anthropic 呼吁 Pace the Frontier | 管的是模型放出力度与安全节奏，**不自动等于 capex 下调** |
| 微软 | 唯一明确下调指引 + 取消/推迟约 2GW 租约；2032 容量 12→38GW | **近端节奏放慢、远端规模仍扩** |
| 甲骨文等云账单高增方 | 云 +121%，capex 大数仍在，FCF 转负 | 用杠杆和现金换容量 |
| 卖方 2027 增速警示 | MS 等 | 预期层的二阶风险，尚未被当期收入证伪 |

把「微软砍近端租约」写成「AI 投资结束」，或把「Pace 倡议」写成「巨头集体 capex 收缩」，都是把两列不同的表粘成一行。

## 政策地缘：Pace ≠ Pause；蒸馏风波如何当观察项

### Pace the Frontier

倡议主语是前沿实验室，谓语是**放慢能力迭代速率**。它可能通过「新模型发布变稀、评测军备降温」影响**短期情绪和硬件点杀叙事**；它**不**等于：

- 推理 Token 停增
- 云厂商停建
- 电网排队消失
- HBM / CoWoS 缺口自行愈合

地方层还有加州 AI 儿童安全法、数据中心选址阻力——这是**落地摩擦**，会拉长电力与园区的时间，不是需求开关。

### 蒸馏风波（单方指控）

- 来源：Anthropic 9/10，154 页，指控 7 家中国实验室约 **1.9 亿次**交互级非法蒸馏。
- 中方否认。
- 截至 **9/12：无刑事、无民事立案公开信息；未经司法定性。**

国内卖方（9/14）把短线读成情绪偏空硬件，中长线读成头部模型与网络安全集中。这是**卖方情景**，不是判决书。

观察项（条件化，不是仓位）：

- 是否出现可核的执法、出口管制细则、云厂商合规断供；
- 是否改变中美模型的 API 可获得性，从而改变 Token 份额；
- 是否只停留在报告战与外交口径。

在上述任一「可核动作」出现前，蒸馏适合放在**尾部风险观察清单**，不适合写成已经发生的供应链断裂。

同期还有「美对华芯片新限制预期」、海外 GPU 龙头收购 Hugging Face、Meta Muse 等事件：分别落在**出口管制预期、应用层入口、生成式产品**，不要塞进同一根因果箭头。

模型层总方向（报告原意重组）：竞赛从「谁先放出更强模型」转向「谁能把单位推理成本打下来」。这与 Token 有效价 -41%、Flash 再降 60%、KV 压缩是同一条河。

## 供应链硬约束：CoWoS / HBM / 电力 / 信用

报告把瓶颈从「需求想象」扳回四件实物：

1. **封装：** 台积电 CoWoS 2026 年末约 **12–14 万片/月**，缺口约 **20%**。再多 capex 承诺，也要经过这道闸。
2. **HBM：** 2026 年市场规模约 **$54.6B**。与 DRAM 挤出、现货 4–5 倍长协是同一约束的不同截面。
3. **电力：** 电网并网排队 **>2000GW**。微软近端砍约 2GW 租约，解释力更接近「电和园区签不下来 / 签慢了」，而不是「算力需求反转」。电力是新硬约束。
4. **信用：** AI 相关发债破 **$250B**；甲骨文债务评级贴近垃圾级。FCF 转负 + 发债扩容，意味着景气的边际买家越来越像**杠杆买家**。GS 所谓「盈利增长依赖少数买家」，和这条信用约束是咬合的。

条件化观察：实体闸门（封装/HBM/电）维持紧张时，即使模型价跌，高端卡与 HBM 仍可以价升量缩；若信用利差明显走阔、近垃圾级云厂商 capex 被评级机构逼停，缺口叙事会先从**最杠杆的买家**裂开，而不是从 Token 曲线裂开。

## 交叉验证结论 + 证伪条件

四条链对照（截至 2026-09-13）：

| 链条 | 量 | 价 | 一句话 |
| --- | --- | --- | --- |
| Token | 周调用仍增，斜率骤降 | 综合有效价较 3 月高点 -41% | 以价换量，模型层最受伤 |
| GPU 租金 | 服务器出货 -10.8% | 新卡即期升、旧卡即期晃、一年期 +80% | 缺口在结构，不在箱数 |
| DRAM / HBM | 产能被 HBM 挤出 | 现货强、倒挂、库存极薄 | 最硬的上游确认 |
| NAND | 消费疲软 | 现货连跌 vs 合约仍正 | 最显眼的劈叉空头 |

**相对更硬的确认：** 算力（租金期限结构 + 服务器 ASP）与 HBM/DRAM。  
**相对更脆的环节：** 模型层变现（流量≠付费）与 NAND（现货已经在打合约的脸）。

### 证伪 / 降温条件（观察框架，不是交易指令）

1. **Token：** 周调用转为持续负增长，且前沿均价也跟着综合有效价一起塌，而不是分层。
2. **GPU：** 新卡即期与一年期同时走弱，买断价停止连涨；出货量二阶下滑被 ASP 下跌追上（量价齐跌）。
3. **存储：** HBM 现货相对长协的 4–5 倍溢价快速收敛；韩系库存从「不足 10 天」回到正常；DDR 倒挂消失。
4. **capex：** 从「仅微软近端下调」扩散到多家云日历指引下修，且长期 GW 目标一并下修——那才接近 Pause，而不是 Pace。
5. **信用：** AI 发债受阻或核心云买家评级事件升级，capex 被融资约束打断。
6. **政策：** 蒸馏从单方报告进入可核执法/管制，或出口管制把可交付算力砍在实处。

未满足以上条件时，更干净的表述是：**景气仍在上游价格与供给闸门上；下游在打价格战；中游开始分卡种；现金和杠杆是隐藏的二阶。**

## 与「只减不加硅基」纪律的对接备忘

> 本节只对接既有纪律，**不构成今日加仓许可，也不改写纪律。**

用户现行纪律：硅基 / 通信 / 中韩半导体 = **只减不加**。本笔记是机制学习，用来更新**观察清单与证伪条件**，不是用来给「只减不加」开例外。

纪律对接的几句实话：

- 本期最硬的确认，恰好落在纪律覆盖的区块（算力、HBM/DRAM、封装、电力）。**确认变硬 ≠ 允许加仓。** 对「只减不加」账户，硬确认的用法是：减的时候更清楚自己在减什么节奏，而不是把周报当通行证。
- 模型层价格战、NAND 现货连跌、出货量二阶、FCF 转负、微软近端 capex 下调、BIS 泡沫警告——这些是纪律存在的理由，不是纪律可以松绑的理由。
- 若未来真要讨论纪律变更，最低门槛应是上面「证伪/降温条件」的**反面持续成立**（例如新卡与长约同步走弱、或信用闸门先裂），并且需要单独的决策记录。本文件不做那件事。

## 给用户的口语短报

听好：这周不是「AI 凉了」，是「账单还在刷、折扣已经开打、闸门还是那几道」。

下游像超市大促——货走得飞快，价被砍到认识你妈都费劲。周 Token 顶到 115 万亿这种天文数，但有效价相对 3 月高点少了四成。中国模型把流量抱走，付钱的结构却不是同一张榜。有人用一成二的流量抠走近一半平台收入，有人流量很大、年化收入垫底。模型厂现在比的不是谁更会写诗，是谁更会把 KV 压小、把推理打便宜。Flash 再降 60%、前沿反手涨到 2.5 倍，这叫分层收割，不叫行业统一跳楼。

中游别被一周 H100 摔 9% 吓进叙事里。一年期还在从 1.7 美金爬到 3.06，新卡还在往上叫价，旧卡开始晃。橱窗挂牌可以平着，买断和月租照涨。服务器出货掉了、均价蹦了——箱数在撒谎，单价在说实话。缺口没消失，缺口换房间了：新卡、长约、整机；不是所有带 GPU 三个字母的东西都在同一间房。

上游更狠，存储自己跟自己劈叉。HBM 把晶圆胃口占掉一块，DRAM 被挤得出现 DDR4 比 DDR5 贵一大截这种鬼倒挂；NAND 现货连跌三周，合约还在装没事。一边是库存不到十天，一边是消费闪存在吐。你要是还把「存储」当一个板块开关，那是在用 2023 年的遥控器打 2026 年的电视。

财报呢？收入基本都兑了，现金开始翻白眼。云账单可以三位数涨，FCF 可以几十亿往下掉——这叫先把发电厂和机柜买下来，不是利润神话永续。微软是唯一公开把近端 capex 往下修、还取消/推迟约 2GW 租约的，但人家 2032 年容量目标是往上翻，不是拔插头。记住口诀：**Pace ≠ Pause。** 实验室喊放慢放模型，不等于电厂停工。真 Pause 得看到多家指引一起砍、长期 GW 一起砍。

政策那出戏，蒸馏报告 154 页、1.9 亿次，听着像谍战。它现在的身份是：单方指控，中方否认，法庭没开张。可以盯，别当判决。卖方爱讲短线砸硬件、长线利好集中——那是他们的剧本，不是你的仓位说明书。

闸门还是老四样：封装缺口大约两成、HBM 贵且挤、电网排队排到天荒、债发了两千五百亿出头。景气最硬的地方在算力和内存；最脆的是模型赚钱能力，外加一块正在独自阴跌的 NAND。2027 增速、信用、管制，是二阶定时器，不是今天的收盘价。

最后对接你的纪律，说人话：**硅基、通信、中韩半导体，只减不加。这篇是上课笔记，不是加仓许可证。** 确认越硬，越说明你纪律盯的地方确实还在烧——所以减的时候心里有数，不是因为周报写得热闹就伸手。伸手的那天，得另开一场会，别偷渡。
