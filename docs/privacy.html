旁窗隐私政策

最后更新：2026-09-01（0.9.0）

旁窗（应用包名 com.pangchuang.app）是一款开源 Android 悬浮窗伴侣。本页供 Google Play 与应用内查阅。

我们收集什么

本应用不运营自有账号服务器。下列数据仅在您的设备上处理，或按您的设置发往您选择的第三方 API：

数据用途去向
屏幕截图（JPEG）识别当前画面、生成陪伴语您填写的视觉 API（如硅基流动）
前台应用名（可选）辅助识别正在使用的 App同上，作为文本提示
API Key、Base URL、模型名调用视觉接口仅存于本机，已关闭云备份
解锁状态记录是否已购买完整陪伴本机；购买本身由 Google Play 处理

本应用不会将截图持久保存到相册，也不会上传到我们控制的服务器。锁屏时自动停止截屏与 API 调用。

第三方服务

  • 视觉 API：由您自行选择（例如 SiliconFlow）。受该服务商隐私政策约束。
  • Google Play 结算：一次性内购 full_unlock。付款信息由 Google 处理，我们不收集银行卡号。

权限

  • 悬浮窗：显示角色与气泡。
  • 屏幕录制（MediaProjection）：完整陪伴截取当前画面；演示模式不使用。
  • 使用情况访问（可选）：读取前台包名。
  • 通知：显示前台服务状态。

应用内购买

演示模式免费。完整陪伴需 Google Play 一次性解锁（约 0.99 美元）。退款遵循 Google Play 政策。

儿童

本应用不面向 13 岁以下儿童，也不会故意收集儿童信息。商店目标年龄建议 18 岁以上（因可能截取任意屏幕内容）。

您的选择

  • 可随时停止服务。
  • 可删除 API Key 并卸载以清除本地配置。
  • 可仅使用演示模式（不向视觉 API 发送截图）。
