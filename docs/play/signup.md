# 注册 Google Play 开发者账号（旁窗）

官方入口：https://play.google.com/console/signup  
帮助：https://support.google.com/googleplay/android-developer/answer/6112435

必须满 18 岁。注册费 **25 美元一次性**，不退（证件或卡信息不符被拒也不退）。个人账号即可，旁窗不需要公司主体。

## 先备齐这些

| 东西 | 要求 |
|------|------|
| Google 账号 | 用你自己长期用的 Gmail。不要新买的号，不要和别人共用。 |
| 银行卡 | Visa / Mastercard / American Express。**不要预付卡、虚拟卡。** 持卡人姓名要和证件一致。 |
| 证件 | 政府签发、带照片：中国居民身份证或护照。照片清晰、四边完整、无反光。 |
| 法定姓名和地址 | 与证件、银行卡账单地址同一套。不要证件是中国、地址填美国。 |
| 手机号 | 能收短信。注册时要 OTP。 |
| 两个邮箱思路 | 联系邮箱（Google 找你，可和 Gmail 相同）+ 商店展示邮箱（用户看见，可另设）。都要能收验证码。 |

开发者名称（商店里显示的发行方）可以和证件姓名不同。应用名「旁窗」是以后创建应用时再填，这里先不要填成应用名也行，填你的名字或工作室名。

## 现场怎么点

1. 电脑打开 https://play.google.com/console/signup ，登录那个 Google 账号。
2. 阅读并接受 [Google Play 开发者分发协议](https://play.google.com/about/developer-distribution-agreement.html)。
3. 账号类型选 **个人 (Personal)**。选完不能改。没有营业执照、邓白氏编码就不要选组织。
4. 关联或新建 **Google 支付资料**：法定全名、国家、详细地址按证件和银行卡账单填。国家选你真实居住地。
5. 付 **USD 25**。账单地址必须和支付资料同一行字，空格和门牌都不要即兴改。
6. 填开发者资料：
   - 开发者名称：商店上显示谁发行了旁窗
   - 联系邮箱、联系电话：收 Google 的 OTP
   - 商店公开邮箱：用户在商品页看见的
7. 身份验证：上传证件。姓名必须和支付资料里的法定全名一致。
8. 若要地址证明：纸质银行账单、话费单或水电单的彩色照片，地址与支付资料逐字相同，印章清楚。
9. 个人账号还可能要求用 **Play 管理中心 App** 在真机上验证你有一台 Android 设备。用同一 Google 账号登录那台手机。

验证通过前，Console 里很多按钮是灰的，这是正常的。可能几小时，也可能几天。不要在失败后连点重试，次数有限，多次失败会变成受限账号。

## 不要做的事

- 用别人的证件或卡
- 支付资料写香港、证件用大陆身份证（或反过来）
- 预付卡 / 虚拟卡付 25 美元
- 买来的「成品开发者账号」
- 为了过审乱开 VPN 换国家

网络不稳可以换一个普通家庭宽带再试。不要为了「看起来像美国」去造一套美国身份。

## 过了之后立刻做的三件事

1. 把这个 Google 账号记下来，以后上传 AAB、收审核邮件都用它。
2. 打开 Play Console，确认身份验证状态是已完成。
3. 回来告诉我「账号好了」。下一步是 GitHub Pages 隐私政策 URL，然后创建应用「旁窗」。

个人账号（2023-11-13 之后）即使验证通过，也还不能直接上生产。要先封闭测试：至少 12 人连续 opt-in 14 天。那是注册之后的事，见 `closed-testing.md`。
