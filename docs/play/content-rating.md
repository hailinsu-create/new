# IARC 内容分级问卷（建议答案）

位置：Play Console → App content → Content ratings  
类别选 **实用工具（Utility / Application）** 或 **娱乐**，不要选游戏。

下列按「旁窗」当前功能填写。AI 陪伴语取决于用户屏幕内容，所以 **User-generated content 选是**。

## 问卷

| 题目（大意） | 选 |
|--------------|----|
| 暴力 | 无 |
| 对人物的性描写 / 裸露 | 无 |
| 语言（脏话） | 无（应用本身无；模型可能跟着屏幕走，不主动设计脏话） |
| 受管制物品（烟酒毒） | 无 |
| 恐怖 / 惊悚 | 无 |
| 对用户位置的分享 | 无 |
| 数字购买 | **是**（一次性 $0.99） |
| 用户之间能否交流 | 否 |
| 用户生成内容 | **是** — 视觉模型根据用户屏幕生成文本 |
| 用户能否分享位置给他人 | 否 |
| 用户能否购买随机物品（抽卡） | 否 |
| 是否包含广告 | 否 |
| 是否可与陌生人聊天 | 否 |
| 是否分享用户的个人资讯 | 否（截图发给用户自己的 API，不是社交分享） |

UGC 相关追问：

- 是否提供过滤不当内容？ **否**（文本来自用户自备 API）
- 是否提供举报？ **否**（无社交）
- 建议在商店说明：陪伴语由用户配置的模型生成，可能反映屏幕上已有的内容。

## 目标受众

- 不要勾选「专为儿童设计」
- 目标年龄：**18+**
- 理由：完整陪伴会截取可能含任何内容的屏幕。
