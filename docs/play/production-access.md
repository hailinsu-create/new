# 申请生产权限（问卷草稿）

封闭测试满 12 人连续 14 天后，Dashboard 会出现申请生产。按你**实际测到的**改，不要原样撒谎。下面是旁窗现有功能对应的诚实底稿。

## 应用是做什么的

旁窗是 Android 悬浮窗伴侣。角色小旁停在别的 App 上层，用用户自己配置的视觉 API 看当前画面，说一两句平静的话。演示模式免费、不截真屏。完整陪伴是 Google Play 一次性内购 `full_unlock`（约 $0.99）。

## 你怎么测的

- 内部测试轨道验证购买、恢复购买、演示模式。
- 封闭测试请测试员从 Play 安装，走隐私同意 → 演示悬浮窗 → 切到其它 App → 从通知返回 → 停止。
- 有 License tester 的账号另测真屏录制授权与锁屏暂停。

把真实人数、轨道名称、测试日期填上。

## 收到了什么反馈

测完再写。例如：有人没找到悬浮窗权限入口；有人以为演示会截屏；某台国产系统上「显示在其他应用上层」路径不同。没有反馈就写「N 名测试员完成了演示路径，问题列表如下」，不要编好评。

## 你改了什么

对照反馈列出版本。例如 0.10.0：完整陪伴前台服务同时声明 mediaProjection 与 specialUse；商店图补了 Live2D 悬浮窗；问卷包补了封闭测试说明。

应用内可查看隐私政策与使用条款。没有账号系统，不收集邮箱。

工具类。不面向儿童。建议目标年龄 18+，因为完整陪伴可能截到屏幕上任何内容。
