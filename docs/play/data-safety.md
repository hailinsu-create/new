# Data safety 填表（直接对照勾选）

位置：Play Console → App content → Data safety

## 总览问题

| 问题 | 答案 |
|------|------|
| 是否收集或分享用户数据？ | **是**（截图与可选前台应用名会发往用户自己配置的第三方 API） |
| 是否加密传输中的数据？ | **是**（默认 HTTPS；仅本机 Ollama 可用 localhost） |
| 用户能否请求删除数据？ | **是** — 我们不保存截图；用户可卸载并删除 API Key。第三方 API 的保留策略由用户选择的服务商决定。 |

开发者**没有**自己的账号后端。仍须把「离开设备的数据」申报为收集/分享。

## 数据类别

### 照片和视频 → 照片

- **收集？** 是（屏幕截图 JPEG，不是相册读取）
- **分享？** 是（发往用户配置的视觉 API）
- **必填还是可选？** 完整陪伴必填；演示模式不收集
- **临时处理？** 可以勾选 ephemeral：应用内存用完即丢弃，不写相册。第三方是否保存由该 API 决定，不要承诺对方不保存。
- **用途：** 应用功能
- **说明（可选英文）：** Screenshots of the current screen are sent to a user-configured vision API to generate companion text. Not saved to the gallery. Paused on lock screen.

### 应用活动 → 已安装的应用

- **收集？** 仅当用户开启「使用情况访问」
- **分享？** 是（前台应用名作为提示发给同一视觉 API）
- **必填还是可选？** 可选
- **用途：** 应用功能

### 财务信息 → 购买记录

- **收集？** 否（Google Play 处理付款）。不要把卡号报成我们收集。
- 若表单问是否使用 Google Play 结算：**是**

### 个人信息和账号

- 姓名/邮箱/账号：否
- 用户凭据：API Key **只存本机**，不上传给我们。不要申报为「收集」。

## 安全实践

- 数据加密传输：是
- 用户可请求删除：是（卸载即清除本机配置；我们无服务器副本）
- 是否独立安全评审：否
- 是否承诺遵守 Play Families：否（非儿童应用）

## 不要勾选

- 位置
- 通讯录
- 短信
- 麦克风（我们不录音）
- 广告 ID
- 设备或其他 ID（除非以后加统计 SDK）
