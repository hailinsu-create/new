默认语言仍是中文（简体），英文见 `listing.md`。下面每条短说明都按 Play **80 字符**上限写过。完整说明远低于 4000 字符。应用名称保持「旁窗」或 `Pangchuang`。

Console：商店上架 → 添加翻译 → 选语言 → 粘贴 Title / Short / Full。没有译文的语言会回落到默认中文。

内购商品名称可先只用中文+英文；其它语言可用英文商品名。Product ID 必须是 `full_unlock`。
