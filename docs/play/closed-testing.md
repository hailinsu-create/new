# Play 封闭测试（个人开发者必做）

2023-11-13 之后注册的**个人** Play 开发者账号，不能直接上生产。必须先跑封闭测试，并且：

- 至少 **12 名测试员已经点过加入（opt-in）**
- 这 12 人要**连续 14 天**保持加入状态
- 14 天倒计时要等两件事同时成立才开始：封闭测试版本**审核通过**，并且 opt-in 人数 ≥ 12

组织账号（公司、D-U-N-S）不受这条限制。Console 仪表盘上写的人数以你账号为准；若仍显示 20，按 Console 走。

官方说明：https://support.google.com/googleplay/android-developer/answer/14151465

内部测试（最多 100 人、自己人）**不算**这条。内部测试只用来验证购买。封闭测试才算 12 人 / 14 天。

## 建议顺序

1. 内部测试：上传 `pangchuang-0.10.0.aab`，把自己的 Gmail 加进 License testing，测购买 / 恢复 / 演示。
2. 同一 AAB 升到**封闭测试**。
3. 用邀请邮件把 opt-in 链接发给至少 15 人（多留几个防退出）。文案见 `tester-invite.md`。
4. 测试员必须：打开链接 → 用 Google 账号接受 → **从 Play 安装**（不是 GitHub debug APK）。
5. Console 里人数 ≥ 12 且版本已通过审核后，等满 14 天。
6. Dashboard → 申请生产权限。问卷草稿见 `production-access.md`。
7. 获准后再点生产「Send for review」。

## 测试员要做什么（给审核看的「有人真的在用」）

请他们装上后做一遍，不必写长反馈：

1. 打开旁窗，读完隐私说明并同意（或点暂不同意再回来同意）。
2. 看一眼「界面语言」，可改可不改。
3. 点「仅演示悬浮窗」，切到微信 / 浏览器 / 设置，确认小旁还在。
4. 点通知回到旁窗，再点「让小旁先休息」。
5. 有 License tester 的人再试：解锁完整陪伴、恢复购买。没有的人不要硬买。

不要雇那种只点加入从不打开应用的「测试员农场」。Google 会看安装和活跃；假量容易把生产申请打回来。

## 人数掉到 12 以下

14 天必须连续。有人退出导致不足 12，倒计时会断。立刻补人，重新凑满后再数 14 天。
