# Play 商店文案（旁窗）

## 应用名称

旁窗

## 简短说明（80 字内）

悬浮窗 Live2D 伴侣，认出你在看什么，用扫地僧口吻陪你说两句。演示免费，完整陪伴一次性解锁。

## 完整说明

旁窗是一款 Android 悬浮窗桌面伴侣。角色「小旁」会漂浮在屏幕一角，识别你正在使用的应用与画面，再用平静、点到为止的中文说一两句陪伴语——不吵、不骂，像路过的扫地僧。

**你可以：**
- 免费试用「演示模式」：体验悬浮窗与 Live2D 口型，不向视觉 API 发送真屏截图
- 一次性解锁「完整陪伴」：连接你自有的视觉 API（默认推荐稳定的 Qwen3-VL-8B），让小旁真正陪你看屏幕

**隐私与透明：**
- 截图仅用于生成陪伴语，发往你自行配置的 API，不会上传到我们控制的服务器
- API Key 仅存本机；锁屏自动暂停截屏与调用
- 应用内提供完整隐私政策

**权限说明：**
- 悬浮窗：显示角色与气泡
- 屏幕录制：截取当前画面供视觉模型分析（完整陪伴必需）
- 使用情况访问（可选）：辅助识别前台 App

视觉 API 费用由你自行承担。Live2D 角色为官方虹色 Mao 样例。
