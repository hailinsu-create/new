# 旁窗隐私政策

最后更新：2026-09-01（0.6.0）

旁窗（「本应用」）是一款开源 Android 悬浮窗伴侣。使用前请阅读本政策。

## 我们收集什么

本应用**不运营自有账号服务器**。下列数据仅在您的设备上处理，或按您的设置发往您选择的第三方 API：

| 数据 | 用途 | 去向 |
|------|------|------|
| 屏幕截图（JPEG） | 识别当前画面、生成陪伴语 | 您填写的视觉 API（如硅基流动） |
| 前台应用名（可选） | 辅助识别正在使用的 App | 同上，作为文本提示 |
| API Key、Base URL、模型名 | 调用视觉接口 | 仅存于本机 SharedPreferences |
| 悬浮窗/录屏/通知权限状态 | 功能运行 | 仅本机 |

本应用**不会**将截图持久保存到相册或上传到我们控制的服务器。每次请求结束后，内存中的帧会被释放。

## 第三方服务

您自行选择并配置 OpenAI 兼容的视觉 API 提供商（例如 SiliconFlow）。向其发送的数据受其隐私政策约束。请仅在信任的服务商处创建 Key，并定期轮换。

## 权限说明

- **悬浮窗**：显示角色与气泡。
- **屏幕录制（MediaProjection）**：截取当前屏幕画面供视觉模型分析；锁屏时自动暂停。
- **使用情况访问（可选）**：读取前台包名，提高 App 识别准确度。
- **通知**：显示前台服务状态。

## 儿童

本应用不面向 13 岁以下儿童，也不会故意收集儿童信息。

## 您的选择

- 可随时停止服务（「让小旁先休息」）。
- 可删除 API Key 并卸载应用以清除本地配置。
- 可仅使用「演示陪伴语」模式（不向视觉 API 发送截图）。
- **完整陪伴**需通过 Google Play 一次性内购解锁（约 $0.99）；购买记录由 Google 处理，本应用仅在本机保存解锁状态。

## 应用内购买

- 商品 ID：`full_unlock`（一次性解锁，非订阅）
- 付款与退款遵循 Google Play 政策
- 演示模式无需购买即可使用
- 我们不会收集您的支付卡信息
