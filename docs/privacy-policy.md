# 旁窗隐私政策

最后更新：2026-09-01（0.9.0）

旁窗（「本应用」，包名 `com.pangchuang.app`）是一款开源 Android 悬浮窗伴侣。网页版：若已启用 GitHub Pages，见 https://hailinsu-create.github.io/new/privacy.html

## 我们收集什么

本应用**不运营自有账号服务器**。下列数据仅在您的设备上处理，或按您的设置发往您选择的第三方 API：

| 数据 | 用途 | 去向 |
|------|------|------|
| 屏幕截图（JPEG） | 识别当前画面、生成陪伴语 | 您填写的视觉 API（如硅基流动） |
| 前台应用名（可选） | 辅助识别正在使用的 App | 同上，作为文本提示 |
| API Key、Base URL、模型名 | 调用视觉接口 | 仅存于本机；已关闭云备份 |
| 解锁状态 | 是否已购买完整陪伴 | 仅本机；付款由 Google Play 处理 |

本应用**不会**将截图持久保存到相册或上传到我们控制的服务器。锁屏时自动停止截屏与 API 调用。

## 第三方服务

- 您自行选择并配置 OpenAI 兼容的视觉 API（例如 SiliconFlow）。
- Google Play 结算用于一次性内购 `full_unlock`。我们不收集银行卡信息。

## 权限说明

- **悬浮窗**：显示角色与气泡。
- **屏幕录制（MediaProjection）**：完整陪伴截取当前屏幕；演示模式不截屏。授权前会再次说明。
- **使用情况访问（可选）**：读取前台包名。
- **通知**：显示前台服务状态。

## 应用内购买

演示模式免费。完整陪伴需 Google Play 一次性解锁（约 $0.99）。退款遵循 Google Play 政策。换机可在应用内恢复购买。

## 儿童

本应用不面向 13 岁以下儿童。因可能截取任意屏幕内容，商店目标年龄建议 18 岁以上。

## 您的选择

- 可随时停止服务（「让小旁先休息」）。
- 可删除 API Key 并卸载应用以清除本地配置。
- 可仅使用「演示陪伴语」模式（不向视觉 API 发送截图）。
- 可在设置中选择界面语言，或跟随系统。
