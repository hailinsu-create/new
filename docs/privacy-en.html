Pangchuang privacy policy

Last updated: 2026-09-01 (0.9.0)

Pangchuang (package com.pangchuang.app) is an open-source Android floating companion. This page is for Google Play and in-app review.

What we collect

The app does not run an account server. The data below is processed on your device, or sent to a third-party API that you choose:

DataUseWhere it goes
Screen JPEGRecognize the current screen and write a companion lineThe vision API you configure (for example SiliconFlow)
Foreground app name (optional)Hint which app is in frontSame API, as a text hint
API key, base URL, model nameCall the vision APIOn device only. Cloud backup is off.
Unlock stateWhether full companion is purchasedOn device. Payment is handled by Google Play.

Screenshots are not saved to the gallery and are not uploaded to a server we control. Capture and API calls stop when the phone is locked.

Third parties

  • Vision API: you choose it (for example SiliconFlow). That provider's privacy policy applies.
  • Google Play Billing: one-time product full_unlock. Google handles payment. We do not collect card numbers.

Permissions

  • Overlay: show the character and bubble.
  • Screen capture (MediaProjection): full companion grabs the current frame. Demo mode does not.
  • Usage access (optional): read the foreground package name.
  • Notifications: show the foreground service status.

In-app purchase

Demo mode is free. Full companion is a Google Play one-time unlock (about USD 0.99). Refunds follow Google Play policy.

Children

This app is not directed at children under 13, and we do not knowingly collect data from children. Play target age should be 18+ because full companion may capture whatever is on screen.

Your choices

  • Stop the companion at any time.
  • Delete the API key and uninstall to clear local settings.
  • Use demo mode only (no screenshots sent to a vision API).
  • Pick the UI language in settings, or follow the system language.
