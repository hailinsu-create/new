## 0. 复核结论（相对「装进安卓」）

当前产品自评约 **7.5/10 桌面小品**，核心玩法可跑，**不能当作可玩手机版**。

| 维度 | 现状 | 安卓缺口 |
|---|---|---|
| 玩法环 | SETUP → 警报锁死 → 观战 → 穿梭/通关；四关冒烟绿 | 规则可复用，不需重做模拟 |
| 输入 | `InputEventKey` + 鼠标左右键；朝向靠 A/D 或右键 | **无触控手势**；手机无右键；1/2/3、空格、X、Esc 在手机上不存在 |
| 布局 | 视口锁 **1280×720 横屏**；HUD 大量绝对 `offset_*` | 刘海/手势条/矮屏会裁切；底栏按钮偏小（约 32px 高） |
| 渲染 | `Forward Plus` + 默认 Vulkan 回落 GL | 中低端机应显式 **兼容/移动渲染** + ETC2/ASTC |
| 导出 | 仅 Linux/Windows Desktop preset | **无 Android preset**、无自适应图标、无包名/权限清单 |
| 性能 | 每帧全图 `_draw` 墙砖 + idle bob + 粒子 | 中端机 40×22 格重绘可能掉帧；需降级开关 |
| 音频 | 程序 WAV 床 + Dummy 在无声卡环境 | 真机可用；注意后台暂停/焦点丢失 |
| 商店 | 无 | 侧载 APK 先于 Play；AAB/签名/targetSdk 36 后置 |

**一句话**：下一阶段不是第 5 关，而是 **触控 + 手机 HUD + Android 导出能在真机点完一局**。

## 2. 阶段 M · 安卓可玩（新最高优先级）

目标：**侧载 APK 在真机上，用手指完成「选关 → 部署三人 → 调射界 → 拉警报 → 看戏 → 失败穿梭或通关」**，不依赖键盘。

### M0 工程底座（小–中，挡导出）

- `project.godot`：`window/handheld/orientation=landscape`；`window/stretch/aspect=keep` 或 `expand`；考虑 `emulate_touch_from_mouse` 方便桌面测触控。
- 渲染：安卓导出用 **Compatibility / Mobile**，不要把 Forward Plus 当手机默认；纹理 **etc2/astc=true**。
- `export_presets.cfg` 增加 **Android**：`application/unique_name=com.ambushloop.game`（已有桌面 id 可对齐）、minSdk **24**、targetSdk 跟随模板（Godot 4.7 常见 35/36）、arm64-v8a（可加 armeabi-v7a 若要覆盖老机）。
- 自适应图标：主图标 ≥192、前景/背景 ≥432（可用现有 `icon.svg` 栅格化占位）。
- 文档：本机需 OpenJDK 17、Android SDK、Godot 4.7.2 **Android export templates**、debug keystore。云环境往往打不出真 APK——验收以本机导出为准。

风险：缺模板/SDK 时 preset 能进仓但 CI 绿不代表装得上。

### M1 触控操作映射（中，挡可玩）

原则：**所有现键盘命令必须有同等大按钮或手势**；WATCHING 仍不能改计划。

| 桌面 | 手机替代 |
|---|---|
| 1/2/3 | 已有左侧队员卡点击（加大热区 ≥48dp） |
| 左键点掩体 | 点击/轻触掩体部署（已接近；确认 `InputEventScreenTouch` 与鼠标共用同一 `_handle_setup_click`） |
| 右键/A/D 朝向 | **拖旋转**：按住已部署队员或「旋转」钮拖方向；或掩体上双指/环形滑条 |
| F/G/B/Tab | 底栏已有部分按钮 → 全部常驻、≥44dp、中文短标签 |
| 空格拉警报 | 底栏主 CTA「拉警报」（已有则加大） |
| X 中止 / P 暂停 / ± 变速 | 观战条：暂停、1×、2×、中止 |
| Esc / M | 设置齿轮 + 静音钮 |
| 复盘 ←/→ | 已有滑条；保证触控可拖 |
| R 清记忆 | 放进设置，二次确认 |

实现要点：

- `_unhandled_input` 同时处理 `InputEventScreenTouch` / `InputEventScreenDrag`（Godot 在部分平台会仿真鼠标，**不要只信鼠标**）。
- 长按掩体显示保护扇（已有 hover 在触控上无效）。
- 绊索：点「绊索工具」后点路线，不要依赖 Tab。

### M2 手机 HUD / 安全区（中）

- 设计锚：**横屏 16:9 逻辑 1280×720**，再用 `DisplayServer.get_display_safe_area()` 给左右底留白（刘海、手势条）。
- 底栏单行变 **双行或可滚动工具条**；避免 8+ 个 120×32 按钮挤爆矮屏。
- 事件日志默认折叠，点「日志」展开；不要永久占右上 320px。
- 教程/战报全宽、字号 ≥16、按钮 ≥48dp。
- 世界地图：双指缩放 + 单指拖（SETUP 拖空白平移，点单位仍选中）；默认 fit 全图。

风险：缩放不能改变模拟坐标；只改 Camera2D。

### M3 性能档（小–中）— **已进仓**

- 设置增加「画质：省电/标准」：省电关闭标题粒子、缩短敌军拖尾、降低 `map_draw` 砖纹密度或缓存为静态纹理。
- `map_draw` 仅在 grid/门变化时重绘到 `ViewportTexture`，避免每帧 880 格 `_draw`。
- 目标：中端机（如 2022 年 4GB 机）观战稳定 ≥30fps。

### M4 真机验收（小，流程）

侧载清单（每条都要在真机勾）：

1. 冷启动到标题 < 数秒，不白屏卡死。  
2. 触控完成院子：部署 3 人、调射界、拉警报、看到战斗、失败或胜利可点继续。  
3. 返回标题 / 续关进度仍在。  
4. 主页键切出再回，模拟暂停、音频不泄漏。  
5. 返回键 = 打开暂停/退出确认，不要直接杀进程（可 `quit_on_go_back` 策略明确）。

冒烟仍跑 headless 桌面；另加 `OS.has_feature("mobile")` 的轻量断言（按钮存在、朝向不依赖 KEY_D）。

## 6. 技术约束备忘（Godot 4.7.2）

- 导出安卓：Editor → Manage Export Templates（与编辑器同版本）。  
- JDK 17 + Android SDK（platform-tools、build-tools、platforms）。  
- 侧载用 **APK + debug keystore** 即可；上架才需要 **Gradle + AAB + release keystore**。  
- minSdk 24 ≈ Android 7.0；优先 **arm64-v8a**。  
- 项目 `config/features` 含 Forward Plus 时，安卓 preset 应覆盖为兼容渲染，避免部分 GPU 直接黑屏。
