## 1. 当前基线

产品已不是「仅冒烟的垂直切片」，而是自评约 **7/10** 的可引导小品：

| 层 | 状态 |
|---|---|
| 启动壳 | 标题 → 任务选择（锁/可出击/首通）→ 简报 → 关卡；Esc 设置；退出确认；战役致谢 |
| 核心环 | 准备布置 → 警报锁死 `PlanState` → `SimClock` 观战 → 逃逸/全灭/中止失败穿梭 / 零逃逸通关 |
| 敢死队味 | 步枪/机枪/侦察、LOS 裁切射界、掩体扇、击杀带预览、门锁决策分叉、绊索/弹包/炸桶、复盘 scrub |
| 回归 | `smoke_test.gd` → `SMOKE_SLICE_COMPLETE` + `SMOKE_OK_LAUNCH_BAR` |
| 导出 | `export_presets.cfg` Linux/Windows（需本机模板） |

**离「同类强商店页 / 约 8+」的缺口**主要是：战场仍偏色块几何、混音只有主音量+嗡鸣、三关无系统化真人平衡、无第四关、无平台/商店集成——**不是缺菜单**。

## 2. 不可破坏的硬规则（全程）

来自蓝图 §1 与 `COMMANDOS_COMPLETE.md`，任何阶段不得打开：

1. 警报后布局 / 朝向 / 开火模式 / 门 / 工具**冻结**；暂停、变速、镜头、复盘只改观看。
2. 存活敌人越界逃逸 → 立即失败；参战小队全灭 → 立即失败；中止亦为失败但保留截止情报。
3. 跨轮回只留**情报 + 上轮计划**；不留伤害、弹药、尸体、成长。
4. 路线作者写死；环境只切换预设备用分支；敌人不自由寻路、不中途反复改线。
5. 侦察观察环**仅 SETUP**；不做会改写战斗信息的真迷雾（除非单独立项并改验收）。
6. 永久排除：战斗中点选微操、攀爬/近战刀/诱饵/载具/多层楼、无限波次、建造经济、程序生成关。
7. 绊索/炸桶只在 `_sim_tick` 结算；禁止渲染帧偷改战斗状态。
8. 冒烟契约不得削弱：三关参考解、几何校验、1×/2× fingerprint、锁关与门锁分叉断言。

## 3. 阶段目标

### 阶段 A · 发售向打磨（把 7 推到约 8）

**范围**：表现与信息设计为主，结算顺序尽量不动。  
**子系统**：`map_draw.gd`、`operator.gd` / `enemy.gd` 剪影、`cover_slot.gd`、`main.gd` HUD/幽灵/战报、`battle_log.gd`、`AudioDirector` + `GameSettings` + `PauseOverlay`、`TutorialOverlay`。  
**风险**：信息过载；混音改动须保持 headless Dummy 不泄漏；绘制层级再次盖住保护扇。

交付标准（验收）：

- 截图中友军 / 敌军 / 幽灵 / 掩体保护方向一眼可辨。
- WATCHING 比 SETUP 更干净（作者路线降噪，实体与还击抬高）。
- Music / SFX 分轨可调；阶段切换床音不炸冒烟。
- 三关各有「典型失败 → 可执行修正」经内部试玩记录（至少记录表，不要求统计显著）。
- 仓道 / 泵站有短引导页（不只靠底部 tip）。

### 阶段 B · 内容扩展

**范围**：新作者关 + 可选关卡数据外置。  
**子系统**：`LevelDef`、`AmbushGrid.rebuild` / `_build_*`、`GameSettings.LEVEL_ORDER`、`title.gd` 任务行、`smoke_test` 参考解。  
**风险**：阻挡与折线不同步（历史 P1）；参考胜未进冒烟会假绿。

交付标准：

- 第 4 关（可选第 5 关）各有**唯一新教学点**（例如双决策点或第二环境玩具），不是新中途动词。
- 每关：参考胜利 + 指定逃逸 + 可控全灭进回归。
- 工具预算不变：绊索 ≤1、弹包一人、门不占槽。
- （可选）`data/levels/*.tres` + 校验器：部署格可站、折线不穿墙、锁门必有备用路线。

### 阶段 C · 平台与发行

**范围**：与玩法正交的发行能力。  
**子系统**：导出 CI、云存字段与 `record_win` 对齐、手柄浏览、ZH/EN 文案表。  
**风险**：云存覆盖进度；手柄在 WATCHING 误开部署。

交付标准：

- 可重复的 Windows/Linux 包产出流程（CI 或文档化一键导出）。
- 手柄能完成：选关 → 部署 → 警报 → 暂停；WATCHING 无部署。
- 关键 UI / 战报可切 EN（或表驱动），默认仍可中文。

### 阶段 D · 显式延期（默认不做）

真迷雾、等轴/像素美术管线、VO/外部原声、Steam 成就图集运营、程序关、ECS 大重构、盟军敢死队式中途动词。若要做，必须单独立项并改写本规划的验收与硬规则附录。

## 5. 建议切片（PR 序列）

保持「每条 PR 后院子可玩 + 三关冒烟仍绿」：

1. **`visual-read-pass`** — A1 剪影与材质；不改 tick。  
2. **`watch-hud-layers`** — A2 + A5 观看降噪与终局摘要。  
3. **`audio-mix-buses`** — A3 分轨；守 headless 音频断言。  
4. **`balance-three-yards`** — A4 只动数值与 smoke 参考部署。  
5. **`mission-tutorials`** — A6 分关教程。  
6. **`level-4-authored`** — B1 新关 + 几何 + 参考胜。  
7. **`level-data-tres`**（可选）— B4，插在更多关之前降风险。  
8. **`platform-export`** — C1–C3 发行能力；不改 `_sim_tick` 顺序。

禁止在上述 PR 夹带：FOW、中途指令、`AudioStreamGenerator` 床（易泄漏）、无断言的新关。

## 6. 验收与度量

### 自动化（每 PR）

```bash
godot --headless --path ambush_loop -s res://scripts/smoke_test.gd
```

必须：`SMOKE_SLICE_COMPLETE`、`SMOKE_OK_LAUNCH_BAR`、exit 0。  
新关必须追加：几何、参考胜、（若有门）开/锁分支。

### 试玩记录（阶段 A 起）

每次内部试玩记：首次警报耗时、失败原因、轮回次数、改了什么、是否看复盘、是否修正已知漏点。  
阶段 A 退出参考（方向性，非统计）：多数人能指出失败的具体位置或时机；第一关可在有限次有效尝试后过关；无人需要靠执行阶段救场。

### 评分锚点

| 分 | 含义 |
|---:|---|
| 7 | 当前：有壳、有三关、可导出说明 |
| 8 | 阶段 A 完成：可读、可听、三关引导与平衡过内部试玩 |
| 9 | 阶段 A+B：≥4 关 + 数据校验，内容量接近小品完整版 |
| 10 | 不作为目标；接近真·盟军敢死队或 3A |
