## 六关速评

参考通关：`README.md` + `smoke_test.gd` `_deploy_ref`。slot 0 基。tick÷60 ≈ 秒。窗口 dump 与冒烟 tick **一致**。

### 第1夜 `yard` 院子：交叉封锁

- **教什么：** 青弧 ≠ 黄锥；红主路 / 橙侧翼；灰狼主路、铁砧东箱、夜枭南闸。
- **第一败（实测）：** 西掩体朝东 0° → 敌3 flank 0.4s，tick **965**（16.1s）。失败牌：「漏网：侧翼 · 敌3 · 0.4s出发 · 东廊 / 改一处：把铁砧转到东箱扫橙线侧翼」。逃逸口「缺口 · 侧翼」（`10`）。
- **第二层：** `second_trap_route=flank`，虚线「橙线东廊绕出」。与第一败一致，**可读**。
- **改一处→胜：** slots **1,2,5** / **90,180,180**，tick **283**（4.7s），第 2 世（dump）/ 第 3 世（冒烟，中间多一次 2× 指纹）。高光「交叉封锁第一枪」，解锁深仓（`13`）。
- **画面：** 砖墙院子、井、衣索，橄榄调。`07` 空布置是本切片最干净的一张图。

### 第2夜 `warehouse` 仓道：弹药窗口

- **教什么：** F 入伏再打、G 弹包给铁砧、东廊油桶靠近才炸。
- **第一败（冒烟，窗口未截故意败）：** 同站位不入伏 → 敌5 flank tick **1419**。
- **第二层：** 文案「过早开火会打空」，路线仍是 flank。虚线在东廊（`15`）。玩家可能以为「站爆心外」就是课——课其实是 **等黄区**。和 ce9dd2d 同一笔债，没修。
- **胜：** 1,3,5 + `_play_hold_pack(1)`，tick **872**，`ambush_armed` + `repack`。窗口 `16`：按钮改成「开火: 入伏再打 / 弹包: 铁砧」，绿条「弹包给铁砧 — 这关就该这样」。
- **画面：** 琥珀货架、钠灯、橙桶。和院子分得开。

### 第3夜 `pump` 泵站：关门之后

- **教什么：** B 锁门不是赢，是改线。决策格 `(13,5)` 之后走紫 `alt`。
- **第一败（冒烟）：** 锁门旧朝向 90/0/180 → `route=alt` tick **1052**。
- **第二层：** `second_trap_route=alt`。窗口 `17` 锁门后：紫虚线、「门已锁闭 — 侧翼改走备用接近」、清单「紫备用」替换「侧翼」、底栏「门: 锁闭 (B)」。**可读，且课在地上。**
- **胜：** 锁门 90/180/180 tick **740**（dump+冒烟）。开锁参考胜 tick **694** 仅冒烟。
- **画面：** 青绿管道，辨识第二好（仅次于信号楼）。

### 第4夜 `railcut` 信号楼：双走廊延迟

- **教什么：** 核墙挡住对射；西廊立刻、东廊 **3.8s**；铁砧朝北等。
- **第一败（冒烟）：** 南闸堆人 2,5,1 → 敌3 flank tick **1191**，文案含「东廊」「3.8」。
- **第二层：** 「南闸堆人会被西廊打空」（`18`）。与探针一致。
- **胜：** 1,4,5 / 270,270,180 tick **818**。
- **画面：** 混凝土核 + 双廊，**六夜里最不像复制粘贴的一张**。此后油库/电台站位模板从这里定死。

### 第5夜 `depot` 油库：三路合围

- **教什么：** 绿暗道 delay **2.2s**；绊索是第四人，铺 `(7,11)`。
- **第一败（冒烟）：** 无绊索 → 敌3 sneak tick **1418**。
- **第二层：** `sneak`，「东廊先到，南闸会空」（`19`）。清单第四项「暗道」。
- **胜：** 1,4,5 / 270,270,180 + Tab `(7,11)` tick **572**。窗口 `20` 清单全绿，「绊索已埋伏」。
- **电台是否还像油库：** **远看像。** `19` 与 `22` 同一矩形、同一西夹缝、同一南闸。油库危橙 + 罐圆；电台磷光 + 碟 + 夹缝。

### 第6夜 `radio` 电台：灯塔回波（终夜）

- **教什么：** 四条路——红脊、橙东廊、绿暗道 3.6s、青碟缝回波 **5.2s**。铁砧要在 **碟台朝南** 等回波，不是东廊朝北那一枪。
- **第一败（实测）：** 无绊索，铁砧已在碟台朝南 → 仍是敌3 **sneak** tick **1502**。失败牌：「漏网：暗道 · 敌3 · 3.6s出发 · 西暗道 / 改一处：Tab 绊索铺西暗道（7,11）」。缺口「暗道」（`23`）。**不是回波。** 这是 playable 门槛刻意对齐后的结果：修好暗道才配看见回波。
- **第二层：** `second_trap_route=sneak`，「暗道 3.6s 要绊索」（`22`）。与第一败一致。回波作为「下一刀」写在 spawn_teaching[1] 和青线上。
- **胜：** 1,4,5 / **270/90/270** + trip `(7,11)` tick **730**。观战 `25` t=6.2s：letterbox「锁死观战 · 终夜」、callout「灯塔回波到了 — 敌5」、铁砧碟台朝南、夜枭锁东廊、西墙绊索还在。通关 `26`：「打中了：5.2s 灯塔回波，绊索抽中」。
- **电台还像不像油库：** 机制上不再是「油库再加一根绊索」——多一条作者路、一个朝南的新站位。视觉上仍是油库换色。朋友包过关；商店页不够。
