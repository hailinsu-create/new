# Ambush Loop — Commandos 2 kit (v0.4.0)

One line: **每种枪两把（同盟 / 轴心），6 格背包取舍，警报里自动开火 + 自动手雷。**

范本是《盟军敢死队 2》：点选单人、点地走、搜刮、埋伏、拉警报、打扫带装。不是全即时 RTS，也不是 28 型号图鉴。

## 武器对照（种类 × 同盟 × 轴心）

每种枪恰好两把。匣、掉落、HUD、冒烟只认这 10 个型号。class 匣（`rifle` / `mg` / …）运行时 resolve 成下表里的稳定型号。

| 种类 | 同盟 | 轴心 | 手感差 |
|------|------|------|--------|
| 手枪 | **M1911** | **卢格** | 卢格更远更稳；1911 备弹多 |
| 步枪 | **M1加兰德** | **Kar98k** | 加兰德半自动快；98K 栓动伤害高 |
| 冲锋枪 | **汤姆逊** | **MP40** | 汤姆逊射速更快；MP40 更稳 |
| 轻机枪 | **BAR** | **MG42** | MG42 射速/弹链碾压；BAR 更准 |
| 狙击 | **春田** | **98K瞄准镜** | 镜 98K 更远更狠；春田稍快 |

删掉的长尾：G43、SVT-40、莫辛、恩菲尔德、PPS-43、MP38、斯登、MG34、布伦、DP-28、韦伯利、P38、TT-33、恩菲尔德T、莫辛PU、M12、伊萨卡37、M30钻枪。散弹不再单开一类（轴心没有对等名枪）。

院子匣：Kar98k / MG42 / 98K瞄准镜 / 手雷 / 地雷 / 弹药 / M1911（手枪 class）/ 汤姆逊（冲锋枪 class）/ 卢格。

手雷外观：同盟 **Mills / Mk2**，轴心 **柄雷（Stiel）**。仍是同一种 `grenade` 库存。

## 背包（敢死队 2 味）

每人独立背包 **6 格**。

| 占格 | 不占格 |
|------|--------|
| 枪（每把 1 格，不叠） | 刀 |
| 手雷（一格最多 3 枚） | 枪上的弹匣 / 弹药池 |
| 地雷（一格最多 2） | |
| 诱饵（一格最多 2） | |

怎么用：

1. 开匣 / 搜尸 → 进包。开局只有刀时，第一把枪自动装备。
2. 已经有枪再捡第二把 → **入包不换手**。I 或底栏 **背包** 点那格 **装备**。
3. 满了就捡不起来：丢掉一格，或走近队友 **T / 递给队友**。
4. 失败重开本夜搜刮，背包清空。跨波次（打扫→下一波）继承。

触控：底栏 **背包**。桌面：`I`。

## 自动手雷

不要手动瞄准抛物线。

**搜刮 / 打扫**

- `G` 或底栏 **雷点**：沿朝向（或工具「雷点」点地）放一个圈。再按 `G` 撤掉。
- 背包里必须有手雷。不消耗，只标记。

**警报中**

每人默认 **自动手雷开**（底栏 **自动雷** 可关）：

1. 库存 ≥ 1，冷却 ≤ 0（丢完 **3.6s**）。
2. 有雷点：敌人走进雷点爆炸半径 → 丢向雷点。
3. 没雷点：敌人在投掷距离（160px）且在朝向锥（半角 52°）内 → 丢向人数最多的那团。
4. **友伤**：落点 `0.55 × 半径` 内有活着的队友 → 不丢。爆炸仍会擦伤圈内队友（取消「无人受伤」星）。
5. 消耗 1 枚。外观按握枪阵营：同盟 Mills/Mk2，轴心柄雷。

警报中不自由走位。火力是自动开火 + 自动手雷，不是即时 RTS。

## RAID 不变

`SCOUT → ALERT → SWEEP`。点选单人、点地走、搜刮、埋伏、多波警报、打扫带装。顶栏是 **警报中 · 第N/M波**，没有「锁死观战」。

## 冒烟

`godot --headless --path ambush_loop -s res://scripts/smoke_test.gd`

必须看到：

- `SMOKE_GAME_VERSION 0.4.0`
- `SMOKE_OK_WEAPON_MODELS n=10`
- `SMOKE_OK_NAMED_CRATES`（院子 Kar98k / M1911，没有 G43/钻枪/散弹匣）
- `SMOKE_OK_BACKPACK` / `SMOKE_OK_BACKPACK_UI`
- `SMOKE_OK_AUTO_GRENADE` / `SMOKE_OK_NADE_MARK`
- `SMOKE_OK_CINEMA`（无「锁死」）
- `SMOKE_SLICE_COMPLETE` + `SMOKE_OK_RAID_LOOP`
