# Ambush Loop — Commandos Raid Contract

One line: **搜刮组火力 → 埋伏拉警报 → 清波打扫带战利品 → 下一波；逃逸/全灭失败。**

```
SCOUT (布置/搜刮) --拉警报--> ALERT (战斗波)
                              | 本波全灭
                              v
                            SWEEP (打扫)
                              | 还有波次 --拉警报--> ALERT
                              | 最后一波 --撤离--> WON
                              |
                              +-- 逃逸 / 小队全灭 --> FAILED
```

Internal enum (HUD 用中文阶段名):

| Phase        | 玩家能做什么                         | 敌人                         |
|--------------|--------------------------------------|------------------------------|
| `SETUP`      | 选人、走路、拾取、埋雷、丢雷、上掩体、调射界 | 未出现                       |
| `WATCHING`   | 自动开火；可丢已持有手雷；暂停/倍速/中止     | 本波按作者路线冲逃逸口       |
| `SWEEP`      | 走路拾取尸体掉落；重组埋伏               | 本波已死，掉落留在地上       |
| `FAILED`     | 看失败卡，继续则重开本夜搜刮（留情报）     | —                            |
| `WON`        | 通关卡，进下一夜                         | —                            |
| `REPLAY`     | 只读时间轴                               | —                            |

## 学了敢死队的哪几刀

Keep:

- 点选单个队员，点地走路（格子 A*），不是 RTS 框选大军。
- 刀/枪/弹药/地雷/手雷/诱饵分人背包，火力靠搜刮组合。
- 警报是提交：埋伏摆好再拉，不是一直无压力清图。
- 尸体/掉落要走过去搜，战利品带进下一波。
- 角色分工还在：灰狼中距、铁砧重火慢步、夜枭长窄快走。

Cut (故意不做全 Commandos / 不做 RTS):

- 不做多层楼、爬管道、开车。
- 不做真迷雾战争重写；夜枭观察环仅搜刮期。
- 警报中不开放自由微操走位（避免变成即时战术 RTS）。可丢已准备的手雷。
- 不做跨失败世继承装备；失败重开本夜搜刮。跨波次才继承背包。
- 不做旁窗 / Live2D。六夜地图资产保留。

## 掉落与背包

每人：`weapon_id`、弹药、`grenades`、`mines`、`decoys`。开局只有刀。

地图匣：`rifle` / `mg` / `scout` / `pistol` / `shotgun` / `ammo` / `grenade` / `mine` / `decoy`。

敌人死亡掉落留在尸体处，**警报中不自动吸入**；打扫期走进拾取范围才进背包，带入下一波。

## 多波

每夜 `waves: Array`（每波一条 spawn 表）。清波 → 打扫 → 再警报。最后一波打扫后 Space/按钮 **撤离封锁** 才 `WON`。

逃逸或全灭：本夜失败，情报保留，装备重置。
