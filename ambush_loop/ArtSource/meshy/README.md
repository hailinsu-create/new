# Meshy path (faced characters only)

Do not run until a real `MESHY_API_KEY` exists (`msy_…`).

```bash
# Dry-run first — no spend.
meshy make ./concept.png -o ambush_loop/ArtSource/meshy/<name>/ --dry-run

# After key is in ~/.config/meshy/api_key or $MESHY_API_KEY:
meshy make ./concept.png -o ambush_loop/ArtSource/meshy/<name>/
```

Ambush Loop operators stay polygon silhouettes until that key is present. Props (crate, ammo can) stay on headless Blender Python — not Meshy.
