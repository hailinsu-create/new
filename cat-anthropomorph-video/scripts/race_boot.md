## 口径（互斥 + 全栈 + 不协同）

1. **两台实例**：镜像与数据盘策略应对齐到同一套 SFW 管线（Qwen + Wan I2V fp16 + 可选超分权重占位）。
2. **任意时刻只开一台**：同时双开会双倍计费且易抢同一份工作目录；开机前确认另一台为 **已关机**。
3. **不协同**：禁止跨机传半成品当默认流程；禁止「先克隆定妆再母机 I2V」。抢到者本机 looklock → 人眼/门禁 → I2V → 超分 → 关机留盘。
4. **关机留盘**：停止实例但 **保留数据盘**；不要「释放并删盘」。
5. **未宣称**：本仓库 **不** 声称已开机、已跑 GPU 或已产生计费；实例已创建只代表实体登记。
6. **余额**：以控制台为准；**未授权不充值**；任何开机/租卡动作均需用户明确授权。

## ComfyUI 启动参数（强制口径）

- **禁止** `--use-sage-attention`：Wan2.1 I2V 易出黑屏/噪点废片（ComfyUI#8573）。
- **Wan I2V 必须** `--force-upcast-attention`（ComfyUI#6987）。
- **Qwen looklock**：fp8mixed OK；**不要**对 Qwen 加 `--force-fp16`；仍禁 sage。
- 推荐：`python main.py --listen 0.0.0.0 --port 6006 --force-upcast-attention`。

## 建议开机步骤（授权后 · 仍只开一台）

1. 控制台确认两台均为关机；选 **025 或 003** 去抢卡（无偏好；谁抢到谁干）。
2. 经用户授权后只启动 **一台**；**不要两台一起 Running**。
3. `source .env` → `bash scripts/restore.sh --apply --group looklock` 与 `--group i2v`（全栈；按盘容量可分步，但角色不再按机拆分）。
4. 按 [`BOOT-v0.1g.md`](../BOOT-v0.1g.md) 本机全流程；完成后 **shutdown 留盘**。

可在本目录新增例如 `scripts/race_status.sh`（只读列实例状态）——**本 PR 不强制提供可执行 API 封装**。
