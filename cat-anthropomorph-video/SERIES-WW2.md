## 制作公约（每条必守）

1. **卡点**：重音 = 动作落点；主曲目标 **120–140 BPM**，重拍落动作，变速对齐。
2. **角色锁定**：一猫一阵营一套主装；跨条禁止换脸、禁止阵营串戏（见下节）。盲测认出率 **≥80%** 才量产。
3. **尺度**：炮火/尘土/旗帜/慢镜冲锋可以；肢解、虐俘、真实尸骸、纳粹符号特写、旭日旗特写不做。
4. **AI 标识**：发布前按平台要求标注 AI 生成（抖音/小红书规则以账号侧为准）。
5. **版权**：参考「构图与瞬间」，不贴原新闻片/电影帧；提示词写「inspired by iconic moment X」。
6. **群演**：剪影 / 背影 / 远景人类或泛用士兵；**禁止**长得像 A/B/C；敌方只载具/剪影。

## 15s 镜头模板（每条套用）

| 时段 | 功能 | 要点 |
| --- | --- | --- |
| **0–1.5s** | 变身钩子 | 真猫实拍 → 军装猫（系列开场签名） |
| **1.5–4s** | 起势 | 建立场景与动机 |
| **4–10s** | 连击 | 2–4 个动作卡点 |
| **10–13.5s** | 高潮 | **首尾帧**锁死（FLF2V 友好）；名构图落点 |
| **13.5–15s** | 收尾 | 余韵 / Logo / 史实字幕（若需要） |

**产能估算（单条）**：约 **5–6 段 I2V** + **4–6 张静图**。

**镜头规则**

- 优先正脸 / 3/4；少持枪，多旗、望远镜、奔跑、抬头。
- 旗文：中远景或运动模糊，避免可读敏感标语特写。
- 飞机 / 舰船：局部或远景；**机徽不入画**（尤其 C 线）。
- 爆炸：远景；猫只做反应，不做血肉奇观。
- 高潮动作 **轮换**：升旗 / 握手 / 敬礼 / 起飞 / 救人 / 冲锋定格——**禁止**连续多条都以升旗收尾。
