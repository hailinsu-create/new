## 照片要求

- 正脸清晰，能确认银灰底 + 深灰虎斑条纹，口鼻与胸口较浅。
- 浅绿色瞳色可辨；折耳形态清楚（小耳向前折下）。
- 非空 `.jpg`，不要滤镜过度、不要遮挡耳朵、不要拼图。

## 放置

```text
refs/cats/B/cat-B-silver-fold.jpg
# 或
refs/cats/B/front.jpg
```

放好后运行 `bash scripts/restore.sh --dry-run`，会把文件同步到 `$INPUT_ROOT/cats/B/raw/`。
