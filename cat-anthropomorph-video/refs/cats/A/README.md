- 正脸清晰，能确认橘色虎斑块位置（头顶、背脊、尾巴）与白色口鼻 / 胸口 / 四爪。
- 琥珀铜色瞳色可辨；直立大耳与耳尖毛簇可见。
- 非空 `.jpg`，不要滤镜过度、不要遮挡耳朵、不要拼图。
