# 旁窗隐私政策

最后更新：2026-09-15（0.14.0）

旁窗是一款开源 Android 悬浮窗伴侣。本应用不运营自有账号服务器。

## 数据处理

- 屏幕截图（JPEG）仅用于生成陪伴语，会发往您自行配置的视觉 API（如硅基流动）。
- 可选「使用情况访问」仅用于读取前台应用名，作为识别提示。
- API Key 与设置仅保存在本机，已关闭云备份。
- 本应用不会将截图保存到相册。锁屏时会释放录屏画面并停止 API，不会把锁屏或 PIN 画面送出。
- 若已开启使用情况访问，键盘、密码管理器、验证器和银行类应用会跳过该次截屏（尽力而为）。

## 权限

悬浮窗为显示角色所需。屏幕录制仅完整陪伴 / 真屏试用需要。通知为可选（方便从通知栏停止）。使用情况访问为可选。演示召唤不截取真屏。发给视觉 API 的截图会遮住悬浮窗角色，以免把小旁送进模型。

## 第三方

视觉 API 由您选择。购买由 Google Play 处理。

## 演示模式

开启「演示陪伴语」时不向视觉 API 发送截图。

## 应用内购买

演示召唤免费。未解锁时可用自己的 Key 真屏试用 6 次成功陪伴语。完整陪伴需 Google Play 一次性解锁（约 $0.99）。付款由 Google 处理。试用计数与解锁标记均存在本机，可被本地改写。
