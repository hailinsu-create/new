# 旁窗隐私政策

最后更新：2026-09-01（0.6.0）

旁窗是一款开源 Android 悬浮窗伴侣。本应用不运营自有账号服务器。

## 数据处理

- 屏幕截图（JPEG）仅用于生成陪伴语，会发往您自行配置的视觉 API（如硅基流动）。
- 可选「使用情况访问」仅用于读取前台应用名，作为识别提示。
- API Key 与设置仅保存在本机，不会上传到我们控制的服务器。
- 本应用不会将截图保存到相册。锁屏时自动停止截屏与 API 调用。

## 权限

悬浮窗、屏幕录制、通知为必需；使用情况访问为可选。

## 第三方

视觉 API 由您选择，受其服务商隐私政策约束。

## 演示模式

开启「演示陪伴语」时不向视觉 API 发送截图。

## 应用内购买

完整陪伴需 Google Play 一次性解锁（约 $0.99）。付款由 Google 处理；演示模式免费。
