# 旁窗使用条款

最后更新：2026-09-01

使用旁窗即表示你同意本条款与隐私政策。

## 服务内容

- 演示模式免费，不截取真屏、不调用视觉 API。
- 完整陪伴为 Google Play 一次性内购（商品 ID：`full_unlock`，约 $0.99），解锁后可在本机使用真屏陪伴。
- 视觉 API 由你自行配置并承担费用；我们不提供模型调用额度。

## 购买与退款

付款、税务与退款遵循 Google Play 政策。我们不收集银行卡信息。换机后可在应用内「恢复购买」。

## 你的责任

- 仅在你有权截取的屏幕内容上使用完整陪伴。
- 不要把旁窗用于窥探他人设备或未经同意的录屏。
- API Key 由你保管；丢失或泄露需自行在服务商处轮换。

## 素材

Live2D 角色为官方虹色 Mao 样例，须遵守 Live2D 样例素材许可。应用代码以 MIT 许可开源。

## 免责

陪伴语由第三方视觉模型生成，可能不准确。本应用按现状提供，不构成建议或担保。
